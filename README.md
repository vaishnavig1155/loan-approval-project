## Overview

This project analyzes **4,269 historical loan applications** to understand how a
bank decides to approve or reject loans, and builds a simple, **explainable
prediction model** that can pre-screen new applications.

Instead of "as many charts as possible", the project follows the
**Business Intelligence flow** taught in the program:

> **Data → Information → Insight → Decision → Action**

organized in five levels:

| Level | Content |
|---|---|
| 1. KPIs | What is happening? — approval rate, loan book size, applicant profile |
| 2. Trends | How decisions behave across segments |
| 3. Drivers | *Why*? Which factors actually drive approval vs rejection |
| 4. Risks & Opportunities | What could go wrong? Where is untapped value? |
| 5. Actions | What the bank should do — six evidence-backed recommendations |

### Key results

- **62.2%** of applications are approved; total approved loan book = **Rs 4,049.7 cr**.
- **CIBIL score is the dominant driver:** approval rate is **10.6%** in the 300–550 band and **99.3–99.7%** in every band above 550.
- Loans **larger than the applicant's total assets are never approved** (0%).
- Education, employment type and dependents have **no measurable effect** (flat ~62% approval) — decisions are fair across demographics.
- Model: **Logistic Regression** — **91.1% accuracy, ROC-AUC 0.973** on a 20% held-out test set; a Random Forest cross-check reaches **99.9%** (CIBIL carries 82% of its feature importance).

## Dataset

**Loan Approval Prediction Dataset** — 4,269 rows × 13 columns (income, CIBIL
score, loan amount & term, asset values, demographics, and the approval
decision).

- Source (Kaggle): <https://www.kaggle.com/datasets/spsingh/loan-approval-prediction-dataset>
- Working data link used in this project: <https://raw.githubusercontent.com/sarahrafiqshaikh/Loan-Approval-Prediction-Analysis/main/loan_approval_dataset.csv>
- A copy is included in `data/loan_approval_dataset.csv`.

### Columns

| Column | Description |
|---|---|
| `loan_id` | Unique application ID |
| `no_of_dependents` | Number of dependents of the applicant |
| `education` | Graduate / Not Graduate |
| `self_employed` | Yes / No |
| `income_annum` | Annual income (INR) |
| `loan_amount` | Requested loan amount (INR) |
| `loan_term` | Loan term (2–20 years) |
| `cibil_score` | Credit score (300–900) |
| `residential_assets_value`, `commercial_assets_value`, `luxury_assets_value`, `bank_asset_value` | Value of assets owned (INR) |
| `loan_status` | Target — Approved / Rejected |

## Quick start

1. Install dependencies (any Python 3.9+):
   ```bash
   pip install -r requirements.txt
   ```
2. Open the notebook:
   ```bash
   jupyter notebook Loan_Approval_Prediction.ipynb
   ```
   (or open it in Google Colab via *File → Upload notebook*).
3. Run all cells. The notebook loads `data/loan_approval_dataset.csv`
   automatically (falls back to the hosted copy if the file is not present),
   regenerates all charts in `outputs/`, and prints the model evaluation.

## What the notebook does, step by step

1. **Load** the dataset.
2. **Clean & validate** — removes stray whitespace from column names and
   values, checks missing values / duplicates / ranges, and corrects 28 rows
   with impossible negative asset values.
3. **Feature engineering** — total assets, loan-to-income ratio,
   loan-to-assets ratio, CIBIL bands.
4. **KPIs & EDA** — executive KPI dashboard, approval rates by CIBIL band,
   demographics, and loan-size ratios (7 charts).
5. **Risks & opportunities** analysis.
6. **Modeling** — 80/20 stratified split, scaled Logistic Regression in a
   sklearn Pipeline; evaluation with accuracy, precision/recall/F1, confusion
   matrix, ROC-AUC; coefficient chart + Random Forest cross-check.
7. **Business actions** — six recommendations with the evidence behind each.
